## Testing Technique

### Equivalence Partitioning

Equivalence Partitioning is a software testing technique used to divide input data into groups or **equivalence classes**.

Each class is expected to behave similarly, so one or more representative values can be selected for testing.

### Example

For a requirement:

> Students can enter marks from 0 to 100.

The equivalence classes are:

| Partition | Range | Valid/Invalid |
|---|---|---|
| P1 | Less than 0 | Invalid |
| P2 | 0–100 | Valid |
| P3 | Greater than 100 | Invalid |
